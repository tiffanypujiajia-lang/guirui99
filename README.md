# guirui99 模拟手机 — v1.5

从用户本机 v1 项目恢复。保留原壁纸、锁屏及应用入口；T-FAMILY 按用户最新六张截图顺序还原，网易云按六张参考还原，其他应用保留原占位内容，不补写剧情。

打开 index.html 本地预览，点击或上滑进入密码页，输入 **0214** 解锁。密码显示 **4 个圆点**，支持屏幕数字键、键盘数字及退格。已输入时右下角为“删除”，清空后为“取消”。

七个图标采用用户原图；相机保持仅展示，T-FAMILY 进入“我的泡泡”列表，点击对话进入聊天页，可返回列表或通过底部指示条返回主屏幕；其他应用保持原功能。

聊天页按六张截图顺序显示 43 条消息、6 个时间标记、5 张图片及更新的右侧头像。进入时从第一条开始，向下滚动依次查看全部记录。8 条语音只展示各自时长，尚未提供音频；输入框可点击并输入文字，发送或回车时不会新增消息，而会在界面中央显示“你已经留言了3条消息，请待他回复后再继续发送”，3秒后自动消失；不生成回复。

详见 ASSETS.md、HANDOFF.md 和 TESTING.md。本版本未部署；部署须先获得用户确认。


## 网易云音乐
点击网易云图标进入“我的 / 音乐”页，同时播放用户提供的《太阳与地球》。底部可暂停/继续；网易云内部切换页面保留播放；退出网易云到主屏幕或其他应用时暂停，重新打开网易云继续播放。

- 音乐 → 我喜欢的音乐（7首）→ 右滑或左上角返回。
- 音乐 → 听歌排行（截图中的所有时间、5行）→ 右滑或左上角返回。
- 播客 → 点赞的单集（3条）→ 右滑或左上角返回播客。
- 笔记 → 用户截图中的1篇笔记。

只有《太阳与地球》接入真实音频，其他歌、播客和笔记中的音乐保留展示。排行榜“最近一周”、添加/搜索/订阅/会员等未提供的后续页面不扩展。若浏览器限制播放，底部提示点击播放重试；无需连接网易云账号。
